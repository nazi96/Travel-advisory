About this Project

Project Overview

World Travel Advisory is a cloud-deployed web application that aggregates official U.S. State Department travel advisories with real-time weather data and curated points of interest for travelers planning trips abroad.

Technology Stack

  • Backend: Python 3.11, Flask, Pydantic, HTTPX
  • Frontend: Server-rendered Jinja2 templates with custom CSS
  • Cloud: Google Cloud Run, Cloud Build, Cloud Storage
  • Data Sources: travel.state.gov, Open-Meteo
  • DevSecOps: GitHub, GitHub Actions CI/CD, Bandit security scanning

Team

  • Nazanin Amini — Backend services & API integration
  • Lorie Blount — Frontend UI & UX design
  • Michael Hawkins — Cloud deployment & DevSecOps

REST API Endpoints

  • GET /api/health — Health check
  • GET /api/countries — List all supported countries
  • GET /api/advisory/<country> — Travel advisory
  • GET /api/weather/<country> — Current weather
  • GET /api/report/<country> — Aggregated report
